# JavaScript Essentials

A collection of JavaScript concepts, exercises, hands-on labs, and a final project completed as part of my JavaScript learning journey. This repository demonstrates core JavaScript fundamentals, DOM manipulation, asynchronous programming, and practical web development through interactive projects.

## 📚 Course Overview

This repository covers essential JavaScript topics including:

* JavaScript Fundamentals
* Variables and Data Types
* Operators and Expressions
* Conditional Statements
* Loops and Iteration
* Functions
* Arrays and Objects
* ES6 Features
* Error Handling and Debugging
* Document Object Model (DOM)
* Event Handling
* Browser APIs
* AJAX (XMLHttpRequest)
* Fetch API
* JSON
* Asynchronous JavaScript
* API Integration
